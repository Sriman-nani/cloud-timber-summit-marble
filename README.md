# SatQuery AI

Ask natural-language questions about satellite imagery. Upload a scene (or load a sample), then get detections, land-cover segmentation, statistics, and change maps with visual overlays.

## What you can do

- Upload JPEG, PNG, TIFF, or GeoTIFF (two files at once for before/after)
- Ask things like “How many buildings?”, “Segment water”, “What changed?”
- Toggle overlay layers, measure distances, export CSV / GeoJSON / PDF / PNG

Imagery is analyzed locally for land cover and change; Grok vision (when available) writes the narrative and refined detections.

## Shortcuts

- `M` measure
- `D` detection boxes
- `S` land-cover overlay
- `0` fit to view
- `Ctrl+Enter` send question
